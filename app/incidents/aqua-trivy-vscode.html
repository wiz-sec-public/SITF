Aqua Trivy VS Code Extension: attack mapped to SITF techniques

Incident10 SITF techniques

This page maps the Aqua Trivy VS Code Extension attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • Malicious Fork PR

Attack path

  1. SITF T-C003: PWN Request / Poisoned Pipeline Execution — hackerbot-claw AI agent exploits pull_request_target · in Trivy GitHub Actions
  2. SITF T-C005: Secret Exfiltration from Workflow — PAT stolen from workflow secrets · in Trivy GitHub Actions
  3. SITF T-V009: Mass Deletion of Repositories — All releases deleted, repository wiped · in GitHub - aquasecurity/trivy
  4. SITF T-C011: Stealing Registry Tokens — OpenVSX publishing token stolen · in Trivy GitHub Actions
  5. SITF T-R001: Abuse Credentials for Registry Access — Stolen OpenVSX token used · in OpenVSX Marketplace
  6. SITF T-R006: Publishing Malicious IDE/Browser Extension — Versions 1.8.12, 1.8.13 with AI payload · in OpenVSX Marketplace
  7. SITF T-E001: Malicious Execution on Endpoint — Trivy extension executes on install · in Developer Workstations
  8. SITF T-E009: Abuse Local AI Tools — Claude, Codex, Gemini, Copilot CLI, Kiro invoked in permissive mode · in Developer Workstations
  9. SITF T-E003: Harvest Local Secrets / Credentials from Endpoint — AI scans for tokens, credentials, financial records · in Developer Workstations
  10. SITF T-E007: Abuse Local VCS Access from Endpoint — gh CLI used to push REPORT.MD to posture-report-trivy · in Developer Workstations

Outcomes

  • Credential Exfiltration via GitHub
  • Destruction

Techniques and controls

TechniqueKey protective controls
T-C003 PWN Request / Poisoned Pipeline ExecutionBranch protection rules (VCS); Private repo (VCS); Require explicit approval/ disallow workflows from forks (VCS)
T-C005 Secret Exfiltration from WorkflowOIDC setup in workflows; Minimal workflow permissions; Log sanitization
T-C011 Stealing Registry TokensOIDC setup in workflows; Trusted publishing (registry)
T-E001 Malicious Execution on EndpointLocal registry proxy with filtering; IDE sandboxing; Mandating signed extensions
T-E003 Harvest Local Secrets / Credentials from EndpointCredential manager enforcement; No production credentials on endpoints; Encrypted credential storage
T-E007 Abuse Local VCS Access from EndpointCredential manager enforcement; Fine-grained PATs with expiration; Mandatory MFA for VCS
T-E009 Abuse Local AI ToolsAcceptable use policy against unapproved AI tools; Approved AI tools with data protection; Code review for AI-generated code
T-R001 Abuse Credentials for Registry AccessMandatory MFA; IDP / SSO setup; CSPM/CNAPP
T-R006 Publishing Malicious IDE/Browser ExtensionExtension signing requirements; Extension review process; MFA for publisher account
T-V009 Mass Deletion of RepositoriesMinimal VCS user permissions; Regular repository backups; Repository deletion approval workflow
