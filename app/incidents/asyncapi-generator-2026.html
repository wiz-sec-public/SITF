This page maps the AsyncAPI Generator (2026) attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Organizations involved: Downstream Consumers

Entry points

  • Malicious Fork PR: PR #2155 by elzotebo999 (deleted)

Attack path

  1. SITF T-C003: PWN Request / Poisoned Pipeline Execution — pull_request_target in manual-netlify-preview.yml · in GitHub Actions (asyncapi/generator)
  2. SITF T-C005: Secret Exfiltration from Workflow — Stole INPUT_GITHUB-TOKEN + NETLIFY_AUTH_TOKEN · in GitHub Actions (asyncapi/generator)
  3. SITF T-C018: Data Exfiltration from CI/CD — Exfil via rentry.co paste service · in GitHub Actions (asyncapi/generator)
  4. SITF T-V001: Abuse Credentials for VCS Access — asyncapi-bot PAT (privileged) · in GitHub (asyncapi org)
  5. SITF T-V010: Malicious Code Modification in Repository — Direct push to next branch (unsigned) · in GitHub (asyncapi org)
  6. SITF T-R004: Publishing Malicious Package — @asyncapi/generator@3.3.1 · in npm (npmjs.com)
  7. SITF T-E001: Malicious Execution on Endpoint — require() triggers Stage 1 (not install scripts) · in Consumer Dev Machines
  8. SITF T-E003: Harvest Local Secrets / Credentials from Endpoint — Miasma v3 credential stealer · in Consumer Dev Machines
  9. SITF T-R004: Publishing Malicious Package — @asyncapi/generator-helpers@1.1.1 · in npm (npmjs.com)
  10. SITF T-E016: Blockchain-Based C2 Infrastructure — Ethereum contract fallback C2 · in Consumer Dev Machines
  11. SITF T-R004: Publishing Malicious Package — @asyncapi/generator-components@0.7.1 · in npm (npmjs.com)
  12. SITF T-E018: BitTorrent DHT for C2 — 6-channel C2: HTTP, Nostr, IPFS, DHT, libp2p, ETH · in Consumer Dev Machines
