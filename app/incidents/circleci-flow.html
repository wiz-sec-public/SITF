CircleCI: attack mapped to SITF techniques

Incident8 SITF techniques

This page maps the CircleCI attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • CircleCI Entry Point
  • Consumer entry point

Attack path

  1. SITF T-E002: Endpoint Phishing — in CircleCI employee
  2. SITF T-E001: Malicious Execution on Endpoint — Malware · in CircleCI employee
  3. SITF T-E003: Harvest Local Secrets / Credentials from Endpoint — Stealing SSO session cookies · in CircleCI employee
  4. SITF T-P001: Abuse Production Credentials from CI/CD — in CircleCI
  5. SITF T-P012: Production Infrastructure Reconnaissance — in CircleCI
  6. SITF T-P011: Steal Secrets from Production Environment — Generating access tokens to customer envs · in CircleCI
  7. SITF T-C001: Abuse Credentials for CI/CD Access — in Customer envs
  8. SITF T-C018: Data Exfiltration from CI/CD — in Customer envs

Outcomes

  • Future Breach

Techniques and controls

TechniqueKey protective controls
T-C001 Abuse Credentials for CI/CD AccessMandatory MFA; IDP / SSO setup; Enforcing fine-grained PATs (VCS)
T-C018 Data Exfiltration from CI/CDLog sanitization; Artifact encryption; Network segmentation (CI/CD from internet)
T-E001 Malicious Execution on EndpointLocal registry proxy with filtering; IDE sandboxing; Mandating signed extensions
T-E002 Endpoint PhishingMandatory MFA; Phishing-resistant authentication; Security awareness training
T-E003 Harvest Local Secrets / Credentials from EndpointCredential manager enforcement; No production credentials on endpoints; Encrypted credential storage
T-P001 Abuse Production Credentials from CI/CDOIDC for deployment (no long-lived credentials); Minimal IAM permissions; Credential rotation
T-P011 Steal Secrets from Production EnvironmentStore encryption keys in HSM (Hardware Security Module); Envelope encryption with key hierarchy; Customer-managed encryption keys (CMEK)
T-P012 Production Infrastructure ReconnaissanceMinimal IAM permissions; API rate limiting and throttling; Network segmentation (production internal)
