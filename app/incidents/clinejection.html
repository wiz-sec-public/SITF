Clinejection: attack mapped to SITF techniques

Incident9 SITF techniques

This page maps the Clinejection attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • Malicious GitHub Issue
  • Consumer entry

Attack path

  1. SITF T-C021: AI Agent Prompt Injection in Workflow — Claude tricked via issue title prompt injection · in Cline GitHub Actions
  2. SITF T-C002: Malicious Execution in Workflow Context — Claude executes npm install from attacker commit · in Cline GitHub Actions
  3. SITF T-C007: Action Cache Poisoning — Cacheract tool poisons node_modules cache · in Cline GitHub Actions
  4. SITF T-C011: Stealing Registry Tokens — VSCE_PAT, OVSX_PAT, NPM_RELEASE_TOKEN exfiltrated · in Cline GitHub Actions
  5. SITF T-R001: Abuse Credentials for Registry Access — Stolen tokens authenticate to registries · in VS Code Marketplace, OpenVSX, npm
  6. SITF T-R006: Publishing Malicious IDE/Browser Extension — Malicious Cline extension to VS Code Marketplace · in VS Code Marketplace, OpenVSX, npm
  7. SITF T-R004: Publishing Malicious Package — Cline CLI 2.3.0 with OpenClaw payload · in VS Code Marketplace, OpenVSX, npm
  8. SITF T-E015: Extension Auto-Update Exploitation — VS Code auto-updates to malicious Cline · in Developer Workstations
  9. SITF T-E001: Malicious Execution on Endpoint — npm postinstall installs OpenClaw · in Developer Workstations

Outcomes

  • Secondary Supply Chain Attack

Techniques and controls

TechniqueKey protective controls
T-C002 Malicious Execution in Workflow ContextPinning 3rd-party actions; Action whitelisting; Automated maintainer reputation and hygiene checks
T-C007 Action Cache PoisoningDon't use actions cache; Workflow ordering; Cache artifact signing / verification
T-C011 Stealing Registry TokensOIDC setup in workflows; Trusted publishing (registry)
T-C021 AI Agent Prompt Injection in WorkflowRestrict AI agent tool permissions; Input sanitization before AI context injection; Require write access to trigger AI-powered workflows
T-E001 Malicious Execution on EndpointLocal registry proxy with filtering; IDE sandboxing; Mandating signed extensions
T-E015 Extension Auto-Update ExploitationExtension update approval workflow; Extension version pinning; Update signature verification
T-R001 Abuse Credentials for Registry AccessMandatory MFA; IDP / SSO setup; CSPM/CNAPP
T-R004 Publishing Malicious PackageTrusted publishing; Provenance attestation; MFA for registry account
T-R006 Publishing Malicious IDE/Browser ExtensionExtension signing requirements; Extension review process; MFA for publisher account
