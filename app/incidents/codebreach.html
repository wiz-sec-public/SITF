  3. SITF T-V001: Abuse Credentials for VCS Access — in aws/aws-sdk-js-v3
  4. SITF T-V010: Malicious Code Modification in Repository — in aws/aws-sdk-js-v3
  5. SITF T-R004: Publishing Malicious Package — aws-sdk-js-v3 · in GitHub and NPM registries
  6. SITF T-E001: Malicious Execution on Endpoint — in Dev endpoints with AWS Console

Techniques and controls

TechniqueKey protective controls
T-C005 Secret Exfiltration from WorkflowOIDC setup in workflows; Minimal workflow permissions; Log sanitization
T-C020 CI/CD Misconfiguration ExploitationCSPM/CNAPP
T-E001 Malicious Execution on EndpointLocal registry proxy with filtering; IDE sandboxing; Mandating signed extensions
T-R004 Publishing Malicious PackageTrusted publishing; Provenance attestation; MFA for registry account
T-V001 Abuse Credentials for VCS AccessMandatory MFA; IDP / SSO setup; Enforcing fine-grained PATs
T-V010 Malicious Code Modification in RepositoryBranch protection rules (VCS); Require code owner approval; Mandatory code review by multiple reviewers
