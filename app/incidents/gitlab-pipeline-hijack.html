GitLab Pipeline Hijack: attack mapped to SITF techniques

Red team engagement4 SITF techniques

This page maps the GitLab Pipeline Hijack engagement to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • External Attacker (Two Accounts)

Attack path

  1. SITF T-C009: CI/CD Vulnerability Exploitation — Pipeline identity hijacking via mirror · in GitLab CI/CD Pipelines
  2. SITF T-C005: Secret Exfiltration from Workflow — CI_JOB_TOKEN theft · in GitLab CI/CD Pipelines
  3. SITF T-V007: Clone Sensitive Repositories — Cloned victim's private repos · in GitLab Enterprise
  4. SITF T-R007: Harvest Data from Private Artifacts — Pulled victim's private images · in GitLab Container Registry

Outcomes

  • Data Exfiltration
  • Supply Chain Risk

Techniques and controls

TechniqueKey protective controls
T-C005 Secret Exfiltration from WorkflowOIDC setup in workflows; Minimal workflow permissions; Log sanitization
T-C009 CI/CD Vulnerability ExploitationUsing managed CI/CD instances; Patching schedule
T-R007 Harvest Data from Private ArtifactsMinimal registry permissions; Artifact encryption
T-V007 Clone Sensitive RepositoriesMinimal VCS permissions; Repository access reviews
