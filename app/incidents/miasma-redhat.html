Miasma (Red Hat): attack mapped to SITF techniques

Incident8 SITF techniques

This page maps the Miasma (Red Hat) attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • Stolen Credentials: Infostealer logs (April 13, 2026)

Attack path

  1. SITF T-V001: Abuse Credentials for VCS Access — Red Hat employee GitHub account · in GitHub (RedHatInsights)
  2. SITF T-V010: Malicious Code Modification in Repository — Injected malicious 'release' workflows · in GitHub (RedHatInsights)
  3. SITF T-C002: Malicious Execution in Workflow Context — Malicious 'release' workflow runs · in GitHub Actions
  4. SITF T-C011: Stealing Registry Tokens — OIDC trusted publishing abused · in GitHub Actions
  5. SITF T-R004: Publishing Malicious Package — 96 versions across 32 packages · in npm (@redhat-cloud-services)
  6. SITF T-R012: Package Lifecycle Script Abuse — 4.2MB obfuscated preinstall payload · in npm (@redhat-cloud-services)
  7. SITF T-E001: Malicious Execution on Endpoint — Payload executes via npm install · in Developer Workstations
  8. SITF T-E003: Harvest Local Secrets / Credentials from Endpoint — Credential harvesting via collectors · in Developer Workstations

Outcomes

  • Secondary Supply Chain Attack: Worm propagation via stolen creds

Techniques and controls

TechniqueKey protective controls
T-C002 Malicious Execution in Workflow ContextPinning 3rd-party actions; Action whitelisting; Automated maintainer reputation and hygiene checks
T-C011 Stealing Registry TokensOIDC setup in workflows; Trusted publishing (registry)
T-E001 Malicious Execution on EndpointLocal registry proxy with filtering; IDE sandboxing; Mandating signed extensions
T-E003 Harvest Local Secrets / Credentials from EndpointCredential manager enforcement; No production credentials on endpoints; Encrypted credential storage
T-R004 Publishing Malicious PackageTrusted publishing; Provenance attestation; MFA for registry account
T-R012 Package Lifecycle Script AbuseDisable lifecycle scripts during installation; Network isolation during package installation; Lockfile integrity verification
T-V001 Abuse Credentials for VCS AccessMandatory MFA; IDP / SSO setup; Enforcing fine-grained PATs
T-V010 Malicious Code Modification in RepositoryBranch protection rules (VCS); Require code owner approval; Mandatory code review by multiple reviewers
