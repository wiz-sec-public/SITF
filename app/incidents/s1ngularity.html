s1ngularity: attack mapped to SITF techniques

Incident12 SITF techniques

This page maps the s1ngularity attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • Vulnerability Exploit

Attack path

  1. SITF T-C003: PWN Request / Poisoned Pipeline Execution — Bash injection via unsanitized PR title · in nrwl/nx GitHub Actions
  2. SITF T-C004: Workflow Script Injection — Triggering publish.yml to exfiltrate npm token · in nrwl/nx GitHub Actions
  3. SITF T-C011: Stealing Registry Tokens — npm token exfiltrated via webhook · in nrwl/nx GitHub Actions
  4. SITF T-R004: Publishing Malicious Package — 8 malicious Nx versions (20.9.0-21.8.0) · in npm Registry
  5. SITF T-E001: Malicious Execution on Endpoint — telemetry.js post-install hook executes · in Developer Workstations (macOS/Linux)
  6. SITF T-E003: Harvest Local Secrets / Credentials from Endpoint — GitHub tokens, npm tokens, SSH keys, crypto wallets · in Developer Workstations (macOS/Linux)
  7. SITF T-V001: Abuse Credentials for VCS Access — Second wave - using leaked GitHub tokens · in Victim GitHub Accounts
  8. SITF T-V003: Secret Exfiltration from Repo — s1ngularity-repository repos for stolen data (triple base64) · in Victim GitHub Accounts
  9. SITF T-E009: Abuse Local AI Tools — Claude, Gemini, Q prompted with --dangerously-skip-permissions · in Developer Workstations (macOS/Linux)
  10. SITF T-V006: Turn Private Repos Public — 5,500+ repos exposed across 400+ orgs · in Victim GitHub Accounts
  11. SITF T-E004: Harvest Local Data from Endpoint — /tmp/inventory.txt file catalog · in Developer Workstations (macOS/Linux)
  12. SITF T-E010: Endpoint Infrastructure Destruction — sudo shutdown -h 0 injected in .bashrc/.zshrc · in Developer Workstations (macOS/Linux)

Outcomes
