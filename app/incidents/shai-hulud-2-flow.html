Shai-Hulud 2.0: attack mapped to SITF techniques

Incident8 SITF techniques

This page maps the Shai-Hulud 2.0 attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • Producer entry point (PostHog, AsyncAPI)
  • Consumer entry point

Attack path

  1. SITF T-C003: PWN Request / Poisoned Pipeline Execution — in Patiernt Zero's GitHub Actions
  2. SITF T-C005: Secret Exfiltration from Workflow — in Patiernt Zero's GitHub Actions
  3. SITF T-C005: Secret Exfiltration from Workflow — in Secondary CI/CD component
  4. SITF T-R004: Publishing Malicious Package — in NPM registry
  5. SITF T-E001: Malicious Execution on Endpoint — in Dev endpoint or CI/CD runner
  6. SITF T-E003: Harvest Local Secrets / Credentials from Endpoint — in Dev endpoint or CI/CD runner
  7. SITF T-V004: Secret Exfiltration from Personal Repo — in GitHub
  8. SITF T-E010: Endpoint Infrastructure Destruction — in Dev endpoint or CI/CD runner
  9. SITF T-E006: Register Local Machine as CI Runner — in Dev endpoint or CI/CD runner

Outcomes

  • Future Breach
  • Ongoing Access

Techniques and controls

TechniqueKey protective controls
T-C003 PWN Request / Poisoned Pipeline ExecutionBranch protection rules (VCS); Private repo (VCS); Require explicit approval/ disallow workflows from forks (VCS)
T-C005 Secret Exfiltration from WorkflowOIDC setup in workflows; Minimal workflow permissions; Log sanitization
T-E001 Malicious Execution on EndpointLocal registry proxy with filtering; IDE sandboxing; Mandating signed extensions
T-E003 Harvest Local Secrets / Credentials from EndpointCredential manager enforcement; No production credentials on endpoints; Encrypted credential storage
T-E006 Register Local Machine as CI RunnerUsing managed runners only; Runner registration approval workflow; Runner registration token protection
T-E010 Endpoint Infrastructure DestructionRegular endpoint backups; Minimal local user privileges; Offline backup storage
T-R004 Publishing Malicious PackageTrusted publishing; Provenance attestation; MFA for registry account
T-V004 Secret Exfiltration from Personal RepoPolicy against using personal repos for work; Security awareness training
