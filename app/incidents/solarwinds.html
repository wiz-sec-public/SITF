SolarWinds: attack mapped to SITF techniques

Incident11 SITF techniques

This page maps the SolarWinds attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • Stolen Credentials

Attack path

  1. SITF T-C001: Abuse Credentials for CI/CD Access — APT29 gains access to SolarWinds build environment (Sep 2019) · in SolarWinds Build Infrastructure
  2. SITF T-C002: Malicious Execution in Workflow Context — SUNSPOT implant monitors MSBuild.exe for Orion builds · in SolarWinds Build Infrastructure
  3. SITF T-C013: Persistence on Self-Hosted Runners — SUNSPOT persists in build environment, injects SUNBURST into Orion.Core.BusinessLayer.dll · in SolarWinds Build Infrastructure
  4. SITF T-R005: Publishing Malicious Container/VM Image — Trojanized Orion updates signed with legitimate SolarWinds certificate (Mar 2020) · in SolarWinds Update Distribution
  5. SITF T-P004: Container Image Poisoning to Production — SUNBURST backdoor executes after 2-week dormancy period · in Victim Production Environments (~18,000 customers)
  6. SITF T-P012: Production Infrastructure Reconnaissance — SUNBURST profiles system, checks for security tools and forensic software · in Victim Production Environments (~18,000 customers)
  7. SITF T-P010: Network Lateral Movement Within Production — TEARDROP/RAINDROP payloads deployed, RDP and SMB lateral movement · in Victim Production Environments (~18,000 customers)
  8. SITF T-E002: Endpoint Phishing — Cobalt Strike Beacon deployed via TEARDROP, C2 established · in Victim Workstations (Government & Enterprise)
  9. SITF T-E003: Harvest Local Secrets / Credentials from Endpoint — Browser credential theft, WMI persistence established · in Victim Workstations (Government & Enterprise)
  10. SITF T-P009: Cloud Service Lateral Movement — OAuth app abuse and service principal compromise for M365/Azure access · in Victim Production Environments (~18,000 customers)
  11. SITF T-P011: Steal Secrets from Production Environment — Credential theft from Chrome browser profiles and service accounts · in Victim Production Environments (~18,000 customers)

Outcomes

  • Persistence Established
  • Secondary Supply Chain Attack

Techniques and controls

TechniqueKey protective controls
T-C001 Abuse Credentials for CI/CD AccessMandatory MFA; IDP / SSO setup; Enforcing fine-grained PATs (VCS)
T-C002 Malicious Execution in Workflow ContextPinning 3rd-party actions; Action whitelisting; Automated maintainer reputation and hygiene checks
T-C013 Persistence on Self-Hosted RunnersUsing managed runners only; Ephemeral runners; Runner isolation
T-E002 Endpoint PhishingMandatory MFA; Phishing-resistant authentication; Security awareness training
T-E003 Harvest Local Secrets / Credentials from EndpointCredential manager enforcement; No production credentials on endpoints; Encrypted credential storage
T-P004 Container Image Poisoning to ProductionImage signing and verification; Provenance attestation; Deployment approval gates
T-P009 Cloud Service Lateral MovementMinimal IAM permissions; Network segmentation; Service mesh / zero trust
T-P010 Network Lateral Movement Within ProductionNetwork segmentation; Micro-segmentation; Security group hardening
T-P011 Steal Secrets from Production EnvironmentStore encryption keys in HSM (Hardware Security Module); Envelope encryption with key hierarchy; Customer-managed encryption keys (CMEK)
T-P012 Production Infrastructure ReconnaissanceMinimal IAM permissions; API rate limiting and throttling; Network segmentation (production internal)
T-R005 Publishing Malicious Container/VM ImageTrusted publishing; Provenance attestation; Image signing and verification
