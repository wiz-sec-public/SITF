Synacktiv CI/CD Red Team Engagement: attack mapped to SITF techniques

Red team engagement3 SITF techniques

This page maps the Synacktiv CI/CD Red Team Engagement engagement to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Organizations involved: Organization

Entry points

  • Leaked Azure DevOps PAT

Attack path

  1. SITF T-C001: Abuse Credentials for CI/CD Access — Leaked PAT → Azure DevOps access · in Azure DevOps
  2. SITF T-C005: Secret Exfiltration from Workflow — Variable Groups extraction · in Azure DevOps
  3. SITF T-C005: Secret Exfiltration from Workflow — Secure Files extraction · in Azure DevOps
  4. SITF T-C005: Secret Exfiltration from Workflow — Service Connections + GitHub PAT · in Azure DevOps
  5. SITF T-P001: Abuse Production Credentials from CI/CD — Azure RM access via Service Principal · in Azure Resource Manager
  6. SITF T-C001: Abuse Credentials for CI/CD Access — GitHub access via stolen PAT · in GitHub Actions
  7. SITF T-C005: Secret Exfiltration from Workflow — Repository & Environment secrets · in GitHub Actions
  8. SITF T-C005: Secret Exfiltration from Workflow — OIDC token abuse for Azure · in GitHub Actions

Outcomes

  • Azure Cloud Compromise

Techniques and controls

TechniqueKey protective controls
T-C001 Abuse Credentials for CI/CD AccessMandatory MFA; IDP / SSO setup; Enforcing fine-grained PATs (VCS)
T-C005 Secret Exfiltration from WorkflowOIDC setup in workflows; Minimal workflow permissions; Log sanitization
T-P001 Abuse Production Credentials from CI/CDOIDC for deployment (no long-lived credentials); Minimal IAM permissions; Credential rotation
