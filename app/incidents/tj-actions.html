tj-actions/changed-files: attack mapped to SITF techniques

This page maps the tj-actions/changed-files attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

  • Producer initial access
  • Consumer initial access

Attack path

  1. SITF T-C003: PWN Request / Poisoned Pipeline Execution — in Sonatype GitHub Actions
  2. SITF T-C005: Secret Exfiltration from Workflow — Exfiltrating maintainer PAT · in Sonatype GitHub Actions
  3. SITF T-V001: Abuse Credentials for VCS Access — in Reviewdog
  4. SITF T-V010: Malicious Code Modification in Repository — reviewdog/actions-setup · in Reviewdog
  5. SITF T-C002: Malicious Execution in Workflow Context — tj-actions/eslint-changed-files · in tj-actions workflows
  6. SITF T-C005: Secret Exfiltration from Workflow — tj-actions/eslint-changed-files · in tj-actions workflows

  8. SITF T-V010: Malicious Code Modification in Repository — reviewdog/actions-setup · in tj-actions org
  9. SITF T-C002: Malicious Execution in Workflow Context — tj-actions/eslint-changed-files · in Coinbase and other consumers of tj-actions/changed-files
  10. SITF T-C018: Data Exfiltration from CI/CD — in Coinbase and other consumers of tj-actions/changed-files

Outcomes

  • Future Breach

Techniques and controls

TechniqueKey protective controls
T-C002 Malicious Execution in Workflow ContextPinning 3rd-party actions; Action whitelisting; Automated maintainer reputation and hygiene checks
T-C003 PWN Request / Poisoned Pipeline ExecutionBranch protection rules (VCS); Private repo (VCS); Require explicit approval/ disallow workflows from forks (VCS)
T-C005 Secret Exfiltration from WorkflowOIDC setup in workflows; Minimal workflow permissions; Log sanitization
T-C018 Data Exfiltration from CI/CDLog sanitization; Artifact encryption; Network segmentation (CI/CD from internet)
T-V001 Abuse Credentials for VCS AccessMandatory MFA; IDP / SSO setup; Enforcing fine-grained PATs
T-V010 Malicious Code Modification in RepositoryBranch protection rules (VCS); Require code owner approval; Mandatory code review by multiple reviewers
