Trivy Act II: attack mapped to SITF techniques

Incident10 SITF techniques

This page maps the Trivy Act II attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • Malicious for PR

Attack path

  1. SITF T-C003: PWN Request / Poisoned Pipeline Execution — Memory dump via /proc/<pid>/mem on Runner.Worker · in GitHub Actions (Initial)
  2. SITF T-C005: Secret Exfiltration from Workflow — Pattern search: {"value":"<secret>","isSecret":true} · in GitHub Actions (Initial)
  3. SITF T-V001: Abuse Credentials for VCS Access — Feb 28: Validate stolen aqua-bot PAT · in GitHub (aquasecurity org)
  4. SITF T-V002: Imposter Commits — Forged as Guillermo Rauch & DmitriyLewen · in GitHub (aquasecurity org)
  5. SITF T-V010: Malicious Code Modification in Repository — 75/76 trivy-action + 7 setup-trivy tags force-pushed · in GitHub (aquasecurity org)
  6. SITF T-C002: Malicious Execution in Workflow Context — Imposter checkout downloads from scan.aquasecurtiy.org · in GitHub Actions (Release)
  7. SITF T-C005: Secret Exfiltration from Workflow — AES-256-CBC + RSA-4096 encrypted as tpcp.tar.gz · in GitHub Actions (Release)
  8. SITF T-C011: Stealing Registry Tokens — Docker Hub, GHCR, AWS ECR tokens stolen · in GitHub Actions (Release)
  9. SITF T-R005: Publishing Malicious Container/VM Image — trivy, tfsec, traceshark poisoned across 3 registries · in Docker Hub / GHCR / AWS ECR
  10. SITF T-R004: Publishing Malicious Package — trivy v0.69.4 binary releases (tar.gz, executables) · in Docker Hub / GHCR / AWS ECR
  11. SITF T-V008: Malicious Repo Hosting — Hidden repo tpcp-docs as fallback exfil channel · in GitHub (aquasecurity org)

Outcomes

  • Secondary Supply Chain Attack
  • Future Breach

Techniques and controls

TechniqueKey protective controls
T-C002 Malicious Execution in Workflow ContextPinning 3rd-party actions; Action whitelisting; Automated maintainer reputation and hygiene checks
T-C003 PWN Request / Poisoned Pipeline ExecutionBranch protection rules (VCS); Private repo (VCS); Require explicit approval/ disallow workflows from forks (VCS)
T-C005 Secret Exfiltration from WorkflowOIDC setup in workflows; Minimal workflow permissions; Log sanitization
T-C011 Stealing Registry TokensOIDC setup in workflows; Trusted publishing (registry)
T-R004 Publishing Malicious PackageTrusted publishing; Provenance attestation; MFA for registry account
T-R005 Publishing Malicious Container/VM ImageTrusted publishing; Provenance attestation; Image signing and verification
T-V001 Abuse Credentials for VCS AccessMandatory MFA; IDP / SSO setup; Enforcing fine-grained PATs
T-V002 Imposter CommitsCommit signing; Requiring code owner approval; Branch protection rules
T-V008 Malicious Repo HostingRepository creation approval; Resource quotas
