Ultralytics: attack mapped to SITF techniques

Incident7 SITF techniques

This page maps the Ultralytics attack to the SDLC Infrastructure Threat Framework (SITF), step by step, from initial access to impact.

Entry points

  • Malicious Fork PR

Attack path

  1. SITF T-C003: PWN Request / Poisoned Pipeline Execution — PRs #18018, #18020 from fork · in Ultralytics GitHub Actions
  2. SITF T-C004: Workflow Script Injection — Malicious branch name injection · in Ultralytics GitHub Actions
  3. SITF T-C011: Stealing Registry Tokens — Legacy PyPI API token stolen · in Ultralytics GitHub Actions
  4. SITF T-R001: Abuse Credentials for Registry Access — Stolen PyPI API token · in PyPI
  5. SITF T-R004: Publishing Malicious Package — Versions 8.3.41, 8.3.42, 8.3.45, 8.3.46 · in PyPI
  6. SITF T-E001: Malicious Execution on Endpoint — pip install ultralytics · in Consumer Systems
  7. SITF T-E005: Cryptomining on Endpoints — XMRig Monero miner · in Consumer Systems

Outcomes

  • Secondary Supply Chain Attack

Techniques and controls

TechniqueKey protective controls
