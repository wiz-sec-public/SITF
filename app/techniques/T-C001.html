SITF technique T-C001: Abuse Credentials for CI/CD Access

Component: CI/CDStage: Initial AccessID: T-C001

Attacker uses stolen credentials to access CI/CD system.

SITF technique T-C001 (Abuse Credentials for CI/CD Access) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Lack of 2FA / phishing protection
  • Default credentials / bad out-of-the-box config
  • Credentials in org public repos
  • Previous breaches
  • Release approval satisfiable by any developer account

Protective controls

  • Mandatory MFA
    OWASP SPVS: V1.1 Identity and Access Management
  • IDP / SSO setup
    OWASP SPVS: V1.1 Identity and Access Management
  • Enforcing fine-grained PATs (VCS)
    OWASP SPVS: V1.1 Identity and Access Management
  • Enforcing PAT expiration (VCS)
    OWASP SPVS: V1.1 Identity and Access Management
  • Dedicated release approver accounts
    OWASP SPVS: V1.1 Identity and Access Management; V4.3 Secure Deployment Practices

Detective controls

  • Secret scanning
    OWASP SPVS: V5.4 Detection & Monitoring
