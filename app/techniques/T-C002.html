SITF technique T-C002: Malicious Execution in Workflow Context

Component: CI/CDStage: Initial AccessID: T-C002

Attacker executes malicious code within CI/CD workflow.

SITF technique T-C002 (Malicious Execution in Workflow Context) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Using untrusted GitHub actions
  • Using untrusted GitHub Apps
  • Using untrusted reusable workflows
  • Using untrusted SW packages on runners
  • Using untrusted container / VM image for runners
  • Lack of GitHub action pinning
  • Build source controllable through workflow inputs

Protective controls

  • Pinning 3rd-party actions
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Action whitelisting
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Automated maintainer reputation and hygiene checks
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Requiring code owner approval (VCS)
    OWASP SPVS: V1.5 Source Code Management Hardening; V2.3 Code Review and Analysis
  • Branch protection rules (VCS)
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Runner SBOM
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Build source validation against protected branches
    OWASP SPVS: V3.1 Security of Pipeline Environment; V3.3 Continuous Security Checks

Detective controls

  • Image scanning
    OWASP SPVS: V5.4 Detection & Monitoring
