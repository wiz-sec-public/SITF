SITF technique T-C003: PWN Request / Poisoned Pipeline Execution

Component: CI/CDStage: Initial AccessID: T-C003

Attacker submits malicious PR that triggers workflow with elevated privileges.

SITF technique T-C003 (PWN Request / Poisoned Pipeline Execution) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Misconfigured repo - visibility
  • Misconfigured VCS access - external contributors
  • Allowing PRs from forks
  • Usage of pull_request_target/workflow_run
  • Default workflow permissions set to WRITE
  • Default workflow permissions set to approve PR
  • Workflows with access to secrets

Protective controls

  • Branch protection rules (VCS)
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Private repo (VCS)
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Require explicit approval/ disallow workflows from forks (VCS)
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Minimal workflow permissions
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit
  • Default workflow permissions not set to approve PRs
    OWASP SPVS: V3.1 Security of Pipeline Environment

Detective controls

  • CICD scanning tools
    OWASP SPVS: V5.4 Detection & Monitoring
