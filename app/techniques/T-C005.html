SITF technique T-C005: Secret Exfiltration from Workflow

Component: CI/CDStage: Discovery and Lateral MovementID: T-C005

Attacker extracts secrets from CI/CD workflow execution.

SITF technique T-C005 (Secret Exfiltration from Workflow) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Workflow with access to secrets
  • No runtime monitoring
  • Secrets in workflow logs
  • Overprivileged secrets
  • Secrets available to workflows on any branch
  • Personal tokens or signing keys stored as CI secrets

Protective controls

  • OIDC setup in workflows
    OWASP SPVS: V1.1 Identity and Access Management; V3.2 Credential Hygiene
  • Minimal workflow permissions
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit
  • Log sanitization
    OWASP SPVS: V2.5 Credential Hygiene
  • Environment-scoped secrets with branch policies
    OWASP SPVS: V3.1 Security of Pipeline Environment; V3.2 Credential Hygiene
  • Network-level runner egress allow-list
    OWASP SPVS: V3.1 Security of Pipeline Environment; V4.4 Transition Security

Detective controls

  • Runtime agent on runner
    OWASP SPVS: V5.4 Detection & Monitoring
  • Secret scanning
    OWASP SPVS: V5.4 Detection & Monitoring
  • Exfiltration workflow detection on new branches
    OWASP SPVS: V5.4 Detection & Monitoring
