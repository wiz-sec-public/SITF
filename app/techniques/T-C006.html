SITF technique T-C006: Secret Enumeration in Workflows Using GitHub Search

Component: CI/CDStage: Discovery and Lateral MovementID: T-C006

Attacker searches public workflows for exposed secrets.

SITF technique T-C006 (Secret Enumeration in Workflows Using GitHub Search) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Workflow with access to secrets
  • Public repositories
  • Secrets in workflow files

Protective controls

  • OIDC setup in workflows
    OWASP SPVS: V1.1 Identity and Access Management; V3.2 Credential Hygiene
  • Private repositories
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Code review for workflows
    OWASP SPVS: V2.3 Code Review and Analysis

Detective controls

  • Secret scanning
    OWASP SPVS: V5.4 Detection & Monitoring
