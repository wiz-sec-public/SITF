SITF technique T-C008: Malicious Workflow Performing Code Modification

Component: CI/CDStage: Post-CompromiseID: T-C008

Attacker uses workflow to modify code or approve PRs.

SITF technique T-C008 (Malicious Workflow Performing Code Modification) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Default workflow permissions set to WRITE
  • Default workflow permissions set to approve PR
  • Workflow with excessive permissions

Protective controls

  • Minimal workflow permissions
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit
  • Default workflow permissions not set to approve PRs
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Code review requirements
    OWASP SPVS: V2.3 Code Review and Analysis

Detective controls

  • CICD scanning tools
    OWASP SPVS: V5.4 Detection & Monitoring
