SITF technique T-C009: CI/CD Vulnerability Exploitation

Component: CI/CDStage: Initial AccessID: T-C009

Attacker exploits vulnerability in CI/CD platform.

SITF technique T-C009 (CI/CD Vulnerability Exploitation) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Non-patched CI/CD instance
  • Known CVEs not addressed
  • Self-hosted CI/CD without security updates

Protective controls

  • Using managed CI/CD instances
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.3 Secure Maintenance Practices
  • Patching schedule
    OWASP SPVS: V5.3 Secure Maintenance Practices

Detective controls

  • Vulnerability scanning
    OWASP SPVS: V5.4 Detection & Monitoring
  • Security update monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • GitLab Pipeline Hijack (red team engagement)
