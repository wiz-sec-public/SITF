SITF technique T-C010: Runner Executing Malicious Package

Component: CI/CDStage: Discovery and Lateral MovementID: T-C010

Malicious package executes on CI/CD runner.

SITF technique T-C010 (Runner Executing Malicious Package) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Using untrusted SW packages on runners
  • No package verification
  • No runtime monitoring
  • Package installation scripts enabled
  • Direct downloads from public registries

Protective controls

  • Local registry proxy with filtering
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Runner SBOM
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Package version pinning
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Package signature verification
    OWASP SPVS: V2.6 3rd Party Library Audit; V3.4 Integrity of Artifacts
  • Disable package installation scripts (--ignore-scripts)
    OWASP SPVS: V2.6 3rd Party Library Audit

Detective controls

  • Runtime agent on runner
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • LiteLLM (October 2026) (incident)
