SITF technique T-C015: Harvest Secrets from Workflows Using ${{toJson(secrets)}}

Component: CI/CDStage: Discovery and Lateral MovementID: T-C015

Attacker uses toJson() to dump all secrets from workflow.

SITF technique T-C015 (Harvest Secrets from Workflows Using ${{toJson(secrets)}}) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Workflow with access to secrets
  • No CICD scanning
  • No runtime monitoring

Protective controls

  • OIDC setup in workflows
    OWASP SPVS: V1.1 Identity and Access Management; V3.2 Credential Hygiene
  • Minimal workflow permissions
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit

Detective controls

  • CICD scanning tools
    OWASP SPVS: V5.4 Detection & Monitoring
  • Runtime agent on runner
    OWASP SPVS: V5.4 Detection & Monitoring
