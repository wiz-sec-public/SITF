SITF technique T-C016: Pivot from Self-Hosted VM Runner into Local Network / Cloud

Component: CI/CDStage: Discovery and Lateral MovementID: T-C016

Attacker uses runner network access to pivot into production.

SITF technique T-C016 (Pivot from Self-Hosted VM Runner into Local Network / Cloud) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Overprivileged runner pod identity
  • Misconfigured runner cluster
  • Self-hosted runner in production network
  • No network segmentation

Protective controls

  • Minimal runner pod privileges
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit
  • Network segmentation
    OWASP SPVS: V4.4 Transition Security
  • Using managed runners only
    OWASP SPVS: V3.1 Security of Pipeline Environment

Detective controls

  • K8s sensor on runner cluster
    OWASP SPVS: V5.4 Detection & Monitoring
  • KSPM on runner cluster
    OWASP SPVS: V5.4 Detection & Monitoring
