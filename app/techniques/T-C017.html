SITF technique T-C017: Pivot from Self-Hosted Container Runner into K8s Cluster

Component: CI/CDStage: Discovery and Lateral MovementID: T-C017

Attacker escapes container runner to access Kubernetes cluster.

SITF technique T-C017 (Pivot from Self-Hosted Container Runner into K8s Cluster) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Overprivileged runner pod identity
  • Misconfigured runner cluster
  • No pod security policies
  • Privileged containers allowed

Protective controls

  • Minimal runner pod privileges
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit
  • Pod security policies
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Using managed runners only
    OWASP SPVS: V3.1 Security of Pipeline Environment

Detective controls

  • K8s sensor on runner cluster
    OWASP SPVS: V5.4 Detection & Monitoring
  • KSPM on runner cluster
    OWASP SPVS: V5.4 Detection & Monitoring
