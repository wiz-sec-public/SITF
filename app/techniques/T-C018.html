SITF technique T-C018: Data Exfiltration from CI/CD

Component: CI/CDStage: Post-CompromiseID: T-C018

Attacker exfiltrates build artifacts, logs, secrets, and sensitive data from CI/CD system over network.

SITF technique T-C018 (Data Exfiltration from CI/CD) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • No network egress monitoring
  • Unrestricted outbound network access from runners
  • Build artifacts contain sensitive data
  • Logs contain secrets or sensitive information
  • No DLP on CI/CD network

Protective controls

  • Log sanitization
    OWASP SPVS: V2.5 Credential Hygiene
  • Artifact encryption
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Network segmentation (CI/CD from internet)
    OWASP SPVS: V4.4 Transition Security

Detective controls

  • Network DLP
    OWASP SPVS: V5.4 Detection & Monitoring
  • Egress traffic monitoring and filtering
    OWASP SPVS: V5.4 Detection & Monitoring
  • Runtime agent on runner
    OWASP SPVS: V5.4 Detection & Monitoring
  • Large data transfer detection
    OWASP SPVS: V5.4 Detection & Monitoring
  • Detection infra on audit logs (CI/CD)
    OWASP SPVS: V5.4 Detection & Monitoring
