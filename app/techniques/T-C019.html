SITF technique T-C019: CI/CD Infrastructure Destruction

Component: CI/CDStage: Post-CompromiseID: T-C019

Attacker destroys CI/CD pipelines, workflows, runners, or build artifacts to disrupt development and deployment operations.

SITF technique T-C019 (CI/CD Infrastructure Destruction) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the CI/CD component (Continuous Integration/Deployment systems).

Risks that enable this technique

  • Overprivileged workflow permissions
  • No backup and recovery
  • Lack of workflow protection
  • No audit log monitoring
  • Insufficient access controls on critical workflows
  • No approval process for infrastructure changes

Protective controls

  • Minimal workflow permissions
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit
  • Regular CI/CD configuration backups
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • Workflow protection rules
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Infrastructure change approval workflow
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • CI/CD recovery procedures
    OWASP SPVS: V5.3 Secure Maintenance Practices; V5.5 Incident Response & Recovery
  • Using managed runners only
    OWASP SPVS: V3.1 Security of Pipeline Environment

Detective controls

  • Detection infra on audit logs (CI/CD)
    OWASP SPVS: V5.4 Detection & Monitoring
  • Immutable audit logs
    OWASP SPVS: V5.4 Detection & Monitoring
