SITF technique T-E001: Malicious Execution on Endpoint

Component: Endpoint/IDEStage: Initial AccessID: T-E001

Attacker executes malicious code on developer workstation.

SITF technique T-E001 (Malicious Execution on Endpoint) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • Using untrusted IDE extensions
  • Using untrusted software packages on endpoints
  • No EDR
  • Lack of application sandboxing
  • Package installation scripts enabled
  • Direct downloads from public registries

Protective controls

  • Local registry proxy with filtering
    OWASP SPVS: V2.6 3rd Party Library Audit
  • IDE sandboxing
    OWASP SPVS: V1.2 Hardening User Machines
  • Mandating signed extensions
    OWASP SPVS: V1.2 Hardening User Machines
  • Package version pinning
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Automated maintainer reputation and hygiene checks
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Application whitelisting
    OWASP SPVS: V1.2 Hardening User Machines
  • Disable package installation scripts (--ignore-scripts)
    OWASP SPVS: V2.6 3rd Party Library Audit

Detective controls

  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
