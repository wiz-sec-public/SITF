SITF technique T-E002: Endpoint Phishing

Component: Endpoint/IDEStage: Initial AccessID: T-E002

Attacker phishes developer to steal credentials or install malware.

SITF technique T-E002 (Endpoint Phishing) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • Lack of 2FA / phishing protection
  • No security awareness training
  • Credentials stored in plaintext
  • No email security controls

Protective controls

  • Mandatory MFA
    OWASP SPVS: V1.1 Identity and Access Management
  • Phishing-resistant authentication
    OWASP SPVS: V1.1 Identity and Access Management
  • Security awareness training
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment
  • Email security (SPF, DMARC, DKIM)
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment

Detective controls

  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • CircleCI (incident)
  • SolarWinds (incident)
