SITF technique T-E003: Harvest Local Secrets / Credentials from Endpoint

Component: Endpoint/IDEStage: Discovery and Lateral MovementID: T-E003

Attacker extracts credentials stored on developer machine.

SITF technique T-E003 (Harvest Local Secrets / Credentials from Endpoint) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • Credentials stored in plaintext
  • Production credentials on developer machines
  • No local DLP
  • SSH keys without passwords
  • Cloud credentials in environment variables

Protective controls

  • Credential manager enforcement
    OWASP SPVS: V1.1 Identity and Access Management; V2.5 Credential Hygiene
  • No production credentials on endpoints
    OWASP SPVS: V1.2 Hardening User Machines; V2.5 Credential Hygiene
  • Encrypted credential storage
    OWASP SPVS: V1.2 Hardening User Machines; V2.5 Credential Hygiene

Detective controls

  • Local DLP
    OWASP SPVS: V5.4 Detection & Monitoring
  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
