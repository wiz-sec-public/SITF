SITF technique T-E004: Harvest Local Data from Endpoint

Component: Endpoint/IDEStage: Post-CompromiseID: T-E004

Attacker exfiltrates source code, documents, or other sensitive data from endpoint.

SITF technique T-E004 (Harvest Local Data from Endpoint) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • No local DLP
  • No EDR
  • Sensitive data stored locally
  • No encryption at rest

Protective controls

  • Data classification and handling policies
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment
  • Encryption at rest
    OWASP SPVS: V5.5 Incident Response & Recovery

Detective controls

  • Local DLP
    OWASP SPVS: V5.4 Detection & Monitoring
  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
  • Network monitoring
