SITF technique T-E005: Cryptomining on Endpoints

Component: Endpoint/IDEStage: Post-CompromiseID: T-E005

Attacker uses endpoint resources for cryptocurrency mining.

SITF technique T-E005 (Cryptomining on Endpoints) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • No EDR
  • Untrusted software packages
  • No resource monitoring

Protective controls

  • Application whitelisting
    OWASP SPVS: V1.2 Hardening User Machines

Detective controls

  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
  • Resource monitoring and alerting
    OWASP SPVS: V5.4 Detection & Monitoring
  • Network monitoring (detect mining pool connections)
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • Ultralytics (incident)
