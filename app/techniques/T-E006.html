SITF technique T-E006: Register Local Machine as CI Runner

Component: Endpoint/IDEStage: Discovery and Lateral MovementID: T-E006

Attacker registers compromised endpoint as self-hosted CI/CD runner.

SITF technique T-E006 (Register Local Machine as CI Runner) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • Ability to register arbitrary machines as runners
  • No runner registration approval process
  • Runner registration tokens not protected

Protective controls

  • Using managed runners only
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Runner registration approval workflow
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Runner registration token protection
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Network segmentation (runners isolated from endpoints)
    OWASP SPVS: V4.4 Transition Security

Detective controls

None mapped yet.
