SITF technique T-E007: Abuse Local VCS Access from Endpoint

Component: Endpoint/IDEStage: Discovery and Lateral MovementID: T-E007

Attacker uses local git credentials to access VCS.

SITF technique T-E007 (Abuse Local VCS Access from Endpoint) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • VCS credentials stored on endpoint
  • No credential rotation
  • Overprivileged VCS access

Protective controls

  • Credential manager enforcement
    OWASP SPVS: V1.1 Identity and Access Management; V2.5 Credential Hygiene
  • Fine-grained PATs with expiration
    OWASP SPVS: V1.1 Identity and Access Management
  • Mandatory MFA for VCS
    OWASP SPVS: V1.1 Identity and Access Management

Detective controls

  • Audit log monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • Aqua Trivy VS Code Extension (incident)
