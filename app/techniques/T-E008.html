SITF technique T-E008: Abuse Local CI/CD Access from Endpoint

Component: Endpoint/IDEStage: Discovery and Lateral MovementID: T-E008

Attacker uses local CI/CD credentials to access CI/CD system.

SITF technique T-E008 (Abuse Local CI/CD Access from Endpoint) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • CI/CD credentials stored on endpoint
  • No credential rotation
  • Overprivileged CI/CD access

Protective controls

  • Credential manager enforcement
    OWASP SPVS: V1.1 Identity and Access Management; V2.5 Credential Hygiene
  • OIDC instead of long-lived tokens
    OWASP SPVS: V1.1 Identity and Access Management; V3.2 Credential Hygiene
  • Mandatory MFA for CI/CD
    OWASP SPVS: V1.1 Identity and Access Management

Detective controls

  • Audit log monitoring
    OWASP SPVS: V5.4 Detection & Monitoring
