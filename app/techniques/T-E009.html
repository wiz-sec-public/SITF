SITF technique T-E009: Abuse Local AI Tools

Component: Endpoint/IDEStage: Discovery and Lateral MovementID: T-E009

Attacker uses AI coding assistants to exfiltrate code or inject malicious suggestions.

SITF technique T-E009 (Abuse Local AI Tools) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • Using untrusted AI tools
  • No acceptable use policy
  • AI tools with excessive permissions
  • Sensitive code sent to AI services

Protective controls

  • Acceptable use policy against unapproved AI tools
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment
  • Approved AI tools with data protection
    OWASP SPVS: V1.4 Developer Tool Operation
  • Code review for AI-generated code
    OWASP SPVS: V1.4 Developer Tool Operation; V2.3 Code Review and Analysis

Detective controls

  • Network monitoring for AI service connections
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • Aqua Trivy VS Code Extension (incident)
  • s1ngularity (incident)
