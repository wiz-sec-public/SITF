SITF technique T-E010: Endpoint Infrastructure Destruction

Component: Endpoint/IDEStage: Post-CompromiseID: T-E010

Attacker destroys or corrupts endpoint systems, data, or configurations to cause operational disruption.

SITF technique T-E010 (Endpoint Infrastructure Destruction) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • No backup and recovery
  • Overprivileged local user accounts
  • No EDR
  • Lack of system integrity monitoring
  • Insufficient access controls on critical system files

Protective controls

  • Regular endpoint backups
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • Minimal local user privileges
    OWASP SPVS: V1.2 Hardening User Machines; V5.1 Access Audit
  • Offline backup storage
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • File system access controls
    OWASP SPVS: V1.2 Hardening User Machines
  • Endpoint recovery procedures
    OWASP SPVS: V5.3 Secure Maintenance Practices; V5.5 Incident Response & Recovery

Detective controls

  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
  • System integrity monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • Shai-Hulud 2.0 (incident)
