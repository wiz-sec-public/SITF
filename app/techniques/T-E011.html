SITF technique T-E011: Unicode Stealth Code Injection

Component: Endpoint/IDEStage: Initial AccessID: T-E011

Attacker uses invisible Unicode characters (variation selectors, zero-width characters) to hide malicious code that doesn't render in code editors but executes normally.

SITF technique T-E011 (Unicode Stealth Code Injection) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • Using untrusted IDE extensions
  • No code review detection of invisible characters
  • Static analysis tools miss unprintable characters
  • Diff tools don't highlight invisible code
  • Developer trust in visual code inspection

Protective controls

  • IDE plugins to visualize invisible characters
    OWASP SPVS: V1.4 Developer Tool Operation
  • Static analysis with Unicode normalization
    OWASP SPVS: V2.1 Secure Coding Practices; V2.4 Perform Security Checks
  • Extension code signing and verification
    OWASP SPVS: V2.1 Secure Coding Practices; V3.4 Integrity of Artifacts
  • Mandatory code review with specialized tools
    OWASP SPVS: V1.5 Source Code Management Hardening; V2.3 Code Review and Analysis

Detective controls

  • Unicode character detection in code review tools
    OWASP SPVS: V5.4 Detection & Monitoring
  • Automated detection of unprintable characters in commits
    OWASP SPVS: V5.4 Detection & Monitoring
