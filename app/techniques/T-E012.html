SITF technique T-E012: SOCKS Proxy Deployment on Endpoint

Component: Endpoint/IDEStage: Post-CompromiseID: T-E012

Attacker deploys SOCKS proxy server on compromised endpoint to route malicious traffic through victim's network and IP address.

SITF technique T-E012 (SOCKS Proxy Deployment on Endpoint) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • No EDR
  • No network egress monitoring
  • Unrestricted outbound connections
  • Endpoint inside corporate network
  • No process monitoring

Protective controls

  • Application whitelisting
    OWASP SPVS: V1.2 Hardening User Machines
  • Network segmentation (endpoints from production)
    OWASP SPVS: V4.4 Transition Security
  • Outbound connection restrictions
    OWASP SPVS: V5.2 Security Standard Enforcement

Detective controls

  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
  • Network egress monitoring and filtering
    OWASP SPVS: V5.4 Detection & Monitoring
  • Anomalous network behavior detection
    OWASP SPVS: V5.4 Detection & Monitoring
