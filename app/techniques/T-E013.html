SITF technique T-E013: Hidden VNC (HVNC) Deployment

Component: Endpoint/IDEStage: Post-CompromiseID: T-E013

Attacker deploys hidden Virtual Network Computing that provides invisible remote desktop access without user awareness.

SITF technique T-E013 (Hidden VNC (HVNC) Deployment) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • No EDR
  • No process monitoring
  • Lack of application sandboxing
  • Privileged user accounts

Protective controls

  • Minimal local user privileges
    OWASP SPVS: V1.2 Hardening User Machines; V5.1 Access Audit

Detective controls

  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
  • Process monitoring and whitelisting
    OWASP SPVS: V5.4 Detection & Monitoring
  • Session activity monitoring
    OWASP SPVS: V5.4 Detection & Monitoring
  • Behavioral analysis for hidden processes
    OWASP SPVS: V5.4 Detection & Monitoring
  • Virtual desktop detection
    OWASP SPVS: V5.4 Detection & Monitoring
