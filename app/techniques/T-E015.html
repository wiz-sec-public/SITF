SITF technique T-E015: Extension Auto-Update Exploitation

Component: Endpoint/IDEStage: Initial AccessID: T-E015

Attacker exploits automatic extension update mechanisms to silently deploy malicious updates to all users without interaction.

SITF technique T-E015 (Extension Auto-Update Exploitation) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • Auto-updates enabled for extensions
  • No update verification
  • Compromised extension publisher accounts
  • No extension version pinning
  • Silent updates without user notification

Protective controls

  • Extension update approval workflow
    OWASP SPVS: V1.2 Hardening User Machines
  • Extension version pinning
    OWASP SPVS: V1.2 Hardening User Machines
  • Update signature verification
    OWASP SPVS: V1.2 Hardening User Machines; V3.4 Integrity of Artifacts
  • Delayed update deployment (canary testing)
    OWASP SPVS: V4.1 Final Security Assessments

Detective controls

  • Extension update monitoring and alerting
    OWASP SPVS: V5.4 Detection & Monitoring
  • Extension marketplace security monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • Clinejection (incident)
