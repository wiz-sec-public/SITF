SITF technique T-E017: Legitimate Service Abuse for C2

Component: Endpoint/IDEStage: Post-CompromiseID: T-E017

Attacker uses legitimate cloud services (Google Calendar, Pastebin, social media, cloud storage) as command and control channels to evade detection.

SITF technique T-E017 (Legitimate Service Abuse for C2) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • Legitimate services not monitored for C2 abuse
  • No content inspection of legitimate service traffic
  • Services whitelisted in security controls
  • No EDR
  • Encoded payloads in legitimate service data

Protective controls

  • Deep content inspection of legitimate service traffic
    OWASP SPVS: V5.2 Security Standard Enforcement; V5.4 Detection & Monitoring

Detective controls

  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
  • Behavioral analysis for unusual service usage patterns
    OWASP SPVS: V5.4 Detection & Monitoring
  • Network traffic anomaly detection
    OWASP SPVS: V5.4 Detection & Monitoring
  • Application-level monitoring
    OWASP SPVS: V5.4 Detection & Monitoring
  • Data exfiltration detection
    OWASP SPVS: V5.4 Detection & Monitoring
