SITF technique T-E018: BitTorrent DHT for C2

Component: Endpoint/IDEStage: Post-CompromiseID: T-E018

Attacker uses BitTorrent Distributed Hash Table network for decentralized command distribution that cannot be shut down.

SITF technique T-E018 (BitTorrent DHT for C2) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • BitTorrent/P2P traffic not monitored
  • DHT network connections appear as normal P2P traffic
  • No EDR
  • Decentralized C2 cannot be taken down
  • P2P protocols not restricted

Protective controls

  • P2P protocol blocking
    OWASP SPVS: V5.2 Security Standard Enforcement
  • Network behavior analysis
    OWASP SPVS: V5.2 Security Standard Enforcement; V5.4 Detection & Monitoring
  • Application whitelisting
    OWASP SPVS: V1.2 Hardening User Machines

Detective controls

  • EDR on endpoint
    OWASP SPVS: V5.4 Detection & Monitoring
  • BitTorrent traffic monitoring and blocking
    OWASP SPVS: V5.4 Detection & Monitoring
  • DHT network connection detection
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • AsyncAPI Generator (2026) (incident)
