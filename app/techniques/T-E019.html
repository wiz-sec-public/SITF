SITF technique T-E019: OAuth Token Abuse for Cross-Organizational Access

Component: Endpoint/IDEStage: Initial AccessID: T-E019

Attacker uses stolen OAuth tokens to impersonate users across organizational boundaries, bypassing SSO/MFA controls via persistent token access.

SITF technique T-E019 (OAuth Token Abuse for Cross-Organizational Access) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Endpoint/IDE component (Developer workstations and development environments).

Risks that enable this technique

  • OAuth tokens stored in browser or credential stores
  • Third-party apps granted excessive OAuth scopes ('Allow All')
  • OAuth tokens not bound to device or IP
  • No monitoring of OAuth token usage across organizations
  • Long-lived OAuth refresh tokens without rotation
  • Third-party vendors with OAuth access to enterprise identity systems
  • No revocation of tokens when third-party is compromised

Protective controls

  • OAuth scope minimization — Restrict third-party OAuth apps to minimal required scopes
    OWASP SPVS: V1.1 Identity and Access Management; V5.1 Access Audit
  • OAuth token binding — Bind OAuth tokens to specific devices, IPs, or client certificates
    OWASP SPVS: V1.1 Identity and Access Management
  • OAuth app approval workflow — Require admin approval for third-party OAuth integrations
    OWASP SPVS: V1.1 Identity and Access Management; V5.1 Access Audit
  • Short-lived OAuth tokens with frequent rotation — Reduce token lifetime and enforce regular re-authentication
    OWASP SPVS: V1.1 Identity and Access Management; V2.5 Credential Hygiene
  • Third-party vendor security assessment — Assess OAuth-connected vendors for security posture before integration
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment; V2.6 3rd Party Library Audit
  • Conditional access policies for OAuth apps — Require MFA re-verification for sensitive OAuth operations
    OWASP SPVS: V1.1 Identity and Access Management

Detective controls

  • OAuth token usage anomaly detection — Detect OAuth tokens used from unexpected locations, devices, or user agents
    OWASP SPVS: V5.4 Detection & Monitoring
  • Cross-organization OAuth activity monitoring — Monitor and alert on OAuth access patterns across organizational boundaries
    OWASP SPVS: V5.4 Detection & Monitoring
  • Third-party OAuth app audit logging — Log all actions performed by third-party OAuth applications
    OWASP SPVS: V5.4 Detection & Monitoring
  • OAuth scope elevation alerting — Alert when OAuth apps request or use elevated scopes
    OWASP SPVS: V5.4 Detection & Monitoring
