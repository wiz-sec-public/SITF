SITF technique T-P001: Abuse Production Credentials from CI/CD

Component: Production/CloudStage: Initial AccessID: T-P001

Attacker extracts production credentials from CI/CD and uses them to access production.

SITF technique T-P001 (Abuse Production Credentials from CI/CD) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Production credentials in CI/CD workflows
  • Long-lived production credentials
  • Overprivileged cloud service accounts
  • No credential rotation

Protective controls

  • OIDC for deployment (no long-lived credentials)
    OWASP SPVS: V1.1 Identity and Access Management; V3.2 Credential Hygiene
  • Minimal IAM permissions
    OWASP SPVS: V5.1 Access Audit
  • Credential rotation
    OWASP SPVS: V2.5 Credential Hygiene
  • Network segmentation from SDLC
    OWASP SPVS: V4.4 Transition Security

Detective controls

  • Secret scanning
    OWASP SPVS: V5.4 Detection & Monitoring

Framework mappings

  • MITRE ATT&CK: T1078.004
