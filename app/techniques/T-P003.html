SITF technique T-P003: Pivot from Self-Hosted Runner to Production Network

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P003

Attacker uses self-hosted runner network access to pivot into production.

SITF technique T-P003 (Pivot from Self-Hosted Runner to Production Network) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Self-hosted runner in production network
  • Weak network segmentation
  • Overprivileged runner identity
  • No network monitoring

Protective controls

  • Network segmentation from SDLC
    OWASP SPVS: V4.4 Transition Security
  • Using managed runners only
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Runner isolation
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Minimal runner privileges
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit

Detective controls

  • Network monitoring
    OWASP SPVS: V5.4 Detection & Monitoring
