SITF technique T-P004: Container Image Poisoning to Production

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P004

Attacker publishes malicious container image that gets deployed to production.

SITF technique T-P004 (Container Image Poisoning to Production) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Lack of image signing/verification
  • No provenance attestation
  • Automatic deployment without review
  • No image scanning

Protective controls

  • Image signing and verification
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Provenance attestation
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Deployment approval gates
    OWASP SPVS: V4.3 Secure Deployment Practices

Detective controls

  • Image vulnerability scanning
    OWASP SPVS: V5.4 Detection & Monitoring
  • Runtime security monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • SolarWinds (incident)
  • TeamPCP Campaign (incident)
