SITF technique T-P005: Infrastructure-as-Code Manipulation

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P005

Attacker modifies IaC to create backdoors in production infrastructure.

SITF technique T-P005 (Infrastructure-as-Code Manipulation) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Insufficient IaC review process
  • Lack of drift detection
  • Overprivileged deployment credentials

Protective controls

  • Code review for IaC changes
    OWASP SPVS: V2.3 Code Review and Analysis
  • Deployment approval gates
    OWASP SPVS: V4.3 Secure Deployment Practices
  • Minimal deployment permissions
    OWASP SPVS: V4.3 Secure Deployment Practices; V5.1 Access Audit
  • CSPM/CNAPP
    OWASP SPVS: V4.2 Compliance Checks; V5.4 Detection & Monitoring

Detective controls

  • Drift detection
    OWASP SPVS: V5.4 Detection & Monitoring

Framework mappings

  • MITRE ATT&CK: T1098
