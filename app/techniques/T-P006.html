SITF technique T-P006: Kubernetes Service Account Token Theft

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P006

Attacker extracts Kubernetes service account tokens from CI/CD.

SITF technique T-P006 (Kubernetes Service Account Token Theft) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Overprivileged service accounts
  • Long-lived tokens
  • Lack of token rotation
  • Tokens in CI/CD secrets

Protective controls

  • OIDC for K8s access
    OWASP SPVS: V1.1 Identity and Access Management
  • Minimal service account permissions
    OWASP SPVS: V5.1 Access Audit
  • Token rotation
    OWASP SPVS: V2.5 Credential Hygiene

Detective controls

  • Secret scanning
    OWASP SPVS: V5.4 Detection & Monitoring
  • Runtime security monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Framework mappings

  • MITRE ATT&CK: T1552.007
