SITF technique T-P007: Cloud Metadata Service Exploitation

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P007

Attacker accesses cloud metadata service to steal additional credentials.

SITF technique T-P007 (Cloud Metadata Service Exploitation) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Metadata service not restricted
  • Overprivileged IAM roles
  • No network segmentation
  • Compromised workload with metadata access

Protective controls

  • Metadata service restrictions
    OWASP SPVS: V5.2 Security Standard Enforcement
  • Minimal IAM permissions
    OWASP SPVS: V5.1 Access Audit
  • Network segmentation
    OWASP SPVS: V4.4 Transition Security
  • IMDSv2 enforcement (AWS)
    OWASP SPVS: V5.2 Security Standard Enforcement

Detective controls

  • Runtime security monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Framework mappings
