SITF technique T-P008: Kubernetes Pod Escape

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P008

Attacker escapes from container to underlying node.

SITF technique T-P008 (Kubernetes Pod Escape) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Privileged containers allowed
  • No pod security policies
  • Overprivileged pod identity
  • Host filesystem mounted

Protective controls

  • Pod security policies
    OWASP SPVS: V3.1 Security of Pipeline Environment
  • Minimal pod privileges
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.1 Access Audit

Detective controls

  • K8s sensor on cluster
    OWASP SPVS: V5.4 Detection & Monitoring
  • KSPM
    OWASP SPVS: V5.4 Detection & Monitoring
  • Runtime security monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Framework mappings
