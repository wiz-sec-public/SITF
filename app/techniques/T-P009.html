SITF technique T-P009: Cloud Service Lateral Movement

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P009

Attacker uses compromised cloud credentials to access other cloud services.

SITF technique T-P009 (Cloud Service Lateral Movement) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Overprivileged IAM roles
  • No network segmentation
  • Lack of service-to-service authentication
  • No audit log monitoring

Protective controls

  • Minimal IAM permissions
    OWASP SPVS: V5.1 Access Audit
  • Network segmentation
    OWASP SPVS: V4.4 Transition Security
  • Service mesh / zero trust
    OWASP SPVS: V4.4 Transition Security
  • CSPM/CNAPP
    OWASP SPVS: V4.2 Compliance Checks; V5.4 Detection & Monitoring

Detective controls

  • Detection infra on audit logs
    OWASP SPVS: V5.4 Detection & Monitoring

Framework mappings

  • MITRE ATT&CK: T1199
  • AWS Threat Technique Catalog: T1199.A002

Observed in

  • LiteLLM (October 2026) (incident)
  • SolarWinds (incident)
