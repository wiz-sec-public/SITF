SITF technique T-P010: Network Lateral Movement Within Production

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P010

Attacker moves between production systems via network.

SITF technique T-P010 (Network Lateral Movement Within Production) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Weak network segmentation
  • Overly permissive security groups
  • No network monitoring
  • Unpatched systems

Protective controls

  • Network segmentation
    OWASP SPVS: V4.4 Transition Security
  • Micro-segmentation
    OWASP SPVS: V4.4 Transition Security
  • Security group hardening
    OWASP SPVS: V4.4 Transition Security
  • Vulnerability management
    OWASP SPVS: V5.3 Secure Maintenance Practices

Detective controls

  • Network monitoring
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • SolarWinds (incident)
