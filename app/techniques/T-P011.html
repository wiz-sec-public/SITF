SITF technique T-P011: Steal Secrets from Production Environment

Component: Production/CloudStage: Post-CompromiseID: T-P011

Attacker accesses production secrets store and exfiltrates customer secrets, tokens, and credentials.

SITF technique T-P011 (Steal Secrets from Production Environment) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Encryption keys accessible in process memory
  • Lack of hardware security module (HSM) for key storage
  • No secrets rotation policies
  • Centralized storage of all customer secrets
  • No data loss prevention (DLP) on production systems
  • Lack of egress traffic monitoring
  • Services configured with personal or admin credentials
  • Admin APIs return stored secrets

Protective controls

  • Store encryption keys in HSM (Hardware Security Module)
    OWASP SPVS: V5.5 Incident Response & Recovery
  • Envelope encryption with key hierarchy
    OWASP SPVS: V5.5 Incident Response & Recovery
  • Customer-managed encryption keys (CMEK)
    OWASP SPVS: V5.5 Incident Response & Recovery
  • Automatic secrets rotation (30-90 days)
    OWASP SPVS: V2.5 Credential Hygiene
  • Secrets segmentation (per-customer isolation)
    OWASP SPVS: V2.5 Credential Hygiene
  • Memory protection and anti-dumping controls
    OWASP SPVS: V5.5 Incident Response & Recovery
  • Service identities instead of personal credentials
    OWASP SPVS: V1.1 Identity and Access Management
  • Write-only secret storage (redact on read)
    OWASP SPVS: V2.5 Credential Hygiene

Detective controls

  • DLP on production systems
    OWASP SPVS: V5.4 Detection & Monitoring
  • Egress traffic monitoring and filtering
    OWASP SPVS: V5.4 Detection & Monitoring
  • Detection infra on audit logs (production)
    OWASP SPVS: V5.4 Detection & Monitoring
  • Large data transfer detection
    OWASP SPVS: V5.4 Detection & Monitoring
