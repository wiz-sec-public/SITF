SITF technique T-P012: Production Infrastructure Reconnaissance

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P012

Attacker enumerates production infrastructure, services, and resources to identify targets and plan attacks.

SITF technique T-P012 (Production Infrastructure Reconnaissance) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Overprivileged IAM roles allowing enumeration
  • No detection of reconnaissance activities
  • Publicly exposed cloud metadata
  • Insufficient network segmentation allowing scanning
  • Verbose error messages revealing infrastructure details
  • Lack of honeypots or deception technology
  • No rate limiting on API calls

Protective controls

  • Minimal IAM permissions
    OWASP SPVS: V5.1 Access Audit
  • API rate limiting and throttling
    OWASP SPVS: V5.2 Security Standard Enforcement
  • Network segmentation (production internal)
    OWASP SPVS: V4.4 Transition Security
  • Metadata service restrictions
    OWASP SPVS: V5.2 Security Standard Enforcement
  • Generic error messages (no infrastructure details)
    OWASP SPVS: V5.2 Security Standard Enforcement

Detective controls

  • Detection infra on audit logs (production)
    OWASP SPVS: V5.4 Detection & Monitoring
  • Honeypots and deception technology
    OWASP SPVS: V5.4 Detection & Monitoring
  • Anomaly detection for enumeration patterns
    OWASP SPVS: V5.4 Detection & Monitoring
