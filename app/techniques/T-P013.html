SITF technique T-P013: Data Exfiltration from Production

Component: Production/CloudStage: Post-CompromiseID: T-P013

Attacker exfiltrates customer data, application data, databases, and sensitive information from production environment over network.

SITF technique T-P013 (Data Exfiltration from Production) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • No network egress monitoring
  • Unrestricted outbound network access
  • No DLP on production systems
  • Backup data accessible and unmonitored
  • Use of encrypted channels to bypass DLP
  • Cloud storage buckets with public access

Protective controls

  • Backup encryption and access controls
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • SSL/TLS inspection
    OWASP SPVS: V5.4 Detection & Monitoring
  • Data classification and handling policies
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment
  • Network segmentation (production from internet)
    OWASP SPVS: V4.4 Transition Security
  • CSPM/CNAPP
    OWASP SPVS: V4.2 Compliance Checks; V5.4 Detection & Monitoring

Detective controls

  • Network DLP
    OWASP SPVS: V5.4 Detection & Monitoring
  • Egress traffic monitoring and filtering
    OWASP SPVS: V5.4 Detection & Monitoring
  • Large data transfer detection
    OWASP SPVS: V5.4 Detection & Monitoring
  • Database activity monitoring
    OWASP SPVS: V5.4 Detection & Monitoring
  • Detection infra on audit logs (production)
    OWASP SPVS: V5.4 Detection & Monitoring
