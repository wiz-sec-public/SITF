SITF technique T-P014: Production Infrastructure Destruction

Component: Production/CloudStage: Post-CompromiseID: T-P014

Attacker destroys production infrastructure, databases, storage, or configurations to cause severe operational disruption and data loss.

SITF technique T-P014 (Production Infrastructure Destruction) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • Overprivileged IAM roles allowing destructive actions
  • No backup and disaster recovery plan
  • Lack of deletion protection on critical resources
  • No audit log monitoring
  • Insufficient access controls on critical infrastructure
  • No approval process for destructive operations
  • Backup data not isolated from production

Protective controls

  • Minimal IAM permissions
    OWASP SPVS: V5.1 Access Audit
  • Regular backups with offsite/offline storage
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • Deletion protection on critical resources
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • Destructive operation approval workflow
    OWASP SPVS: V4.3 Secure Deployment Practices
  • Immutable backups
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • Disaster recovery procedures and testing
    OWASP SPVS: V5.3 Secure Maintenance Practices; V5.5 Incident Response & Recovery
  • Resource tagging and protection policies
    OWASP SPVS: V4.2 Compliance Checks
  • Backup isolation from production network
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • CSPM/CNAPP
    OWASP SPVS: V4.2 Compliance Checks; V5.4 Detection & Monitoring

Detective controls

  • Detection infra on audit logs (production)
    OWASP SPVS: V5.4 Detection & Monitoring
