SITF technique T-P015: Malicious Service Provisioning for Persistence

Component: Production/CloudStage: Post-CompromiseID: T-P015

Attacker provisions new malicious services or backdoors existing services in orchestration platform (e.g., ArgoCD, Kubernetes) to establish persistence.

SITF technique T-P015 (Malicious Service Provisioning for Persistence) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • No approval gates for service provisioning
  • Developers can create arbitrary services
  • Service definitions not audited
  • No anomaly detection for new service creation
  • Persistent backdoor services remain undetected

Protective controls

  • Deployment approval gates for new services
    OWASP SPVS: V4.3 Secure Deployment Practices
  • Code review for all IaC changes
    OWASP SPVS: V2.3 Code Review and Analysis
  • Baseline approved services list
    OWASP SPVS: V4.2 Compliance Checks
  • CSPM/CNAPP
    OWASP SPVS: V4.2 Compliance Checks; V5.4 Detection & Monitoring

Detective controls

  • Detection infra on audit logs (production)
    OWASP SPVS: V5.4 Detection & Monitoring
  • Anomaly detection for new service creation patterns
    OWASP SPVS: V5.4 Detection & Monitoring
  • Immutable audit logs
    OWASP SPVS: V5.4 Detection & Monitoring
  • Regular service inventory audits
    OWASP SPVS: V5.4 Detection & Monitoring
