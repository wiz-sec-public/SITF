SITF technique T-P016: Supply Chain Backdoor (Sensor/Agent Poisoning)

Component: Production/CloudStage: Discovery and Lateral MovementID: T-P016

Attacker injects backdoor into security sensors, agents, or client-distributed software, causing downstream supply chain compromise affecting all customers.

SITF technique T-P016 (Supply Chain Backdoor (Sensor/Agent Poisoning)) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Production/Cloud component (Production infrastructure of the producer organization).

Risks that enable this technique

  • No binary signing verification for distributed software
  • Customer updates automatically deployed without verification
  • No provenance attestation for sensor binaries
  • No multi-party approval for releases

Protective controls

  • Code signing and verification for all distributed binaries
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Provenance attestation (SLSA Level 3+)
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Customer-controlled update policies with verification
    OWASP SPVS: V4.1 Final Security Assessments
  • Separation of duties for release signing
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Immutable build logs and attestations
    OWASP SPVS: V3.4 Integrity of Artifacts

Detective controls

  • Multi-party approval for sensor/agent releases
    OWASP SPVS: V5.4 Detection & Monitoring
  • Regular security audits of build infrastructure
    OWASP SPVS: V5.4 Detection & Monitoring
