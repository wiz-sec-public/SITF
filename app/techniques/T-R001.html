SITF technique T-R001: Abuse Credentials for Registry Access

Component: RegistryStage: Initial AccessID: T-R001

Attacker uses stolen credentials to access registry.

SITF technique T-R001 (Abuse Credentials for Registry Access) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Registry component (Container and artifact registries (NPM, Docker, PyPI)).

Risks that enable this technique

  • Lack of 2FA / phishing protection
  • Default credentials / bad out-of-the-box config
  • Credentials in public images
  • Credentials in workflow logs
  • Previous breaches

Protective controls

  • Mandatory MFA
    OWASP SPVS: V1.1 Identity and Access Management
  • IDP / SSO setup
    OWASP SPVS: V1.1 Identity and Access Management
  • CSPM/CNAPP
    OWASP SPVS: V4.2 Compliance Checks; V5.4 Detection & Monitoring

Detective controls

  • Secret scanning
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • Aqua Trivy VS Code Extension (incident)
  • Clinejection (incident)
  • TeamPCP Campaign (incident)
  • Trust Wallet (incident)
  • Ultralytics (incident)
