SITF technique T-R002: Misconfigured / Anonymous Access

Component: RegistryStage: Initial AccessID: T-R002

Attacker exploits misconfigured registry permissions.

SITF technique T-R002 (Misconfigured / Anonymous Access) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Registry component (Container and artifact registries (NPM, Docker, PyPI)).

Risks that enable this technique

  • Misconfigured registry access
  • Anonymous access enabled
  • Overly permissive access controls

Protective controls

  • IDP / SSO setup
    OWASP SPVS: V1.1 Identity and Access Management
  • Access control reviews
    OWASP SPVS: V5.1 Access Audit
  • Principle of least privilege
    OWASP SPVS: V5.1 Access Audit
  • CSPM/CNAPP
    OWASP SPVS: V4.2 Compliance Checks; V5.4 Detection & Monitoring

Detective controls

None mapped yet.
