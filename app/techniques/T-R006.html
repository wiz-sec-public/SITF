SITF technique T-R006: Publishing Malicious IDE/Browser Extension

Component: RegistryStage: Discovery and Lateral MovementID: T-R006

Attacker publishes malicious extension to extension marketplace.

SITF technique T-R006 (Publishing Malicious IDE/Browser Extension) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Registry component (Container and artifact registries (NPM, Docker, PyPI)).

Risks that enable this technique

  • Overprivileged publishing credentials
  • No extension review process
  • No signing requirements

Protective controls

  • Extension signing requirements
    OWASP SPVS: V4.1 Final Security Assessments
  • Extension review process
    OWASP SPVS: V4.1 Final Security Assessments
  • MFA for publisher account
    OWASP SPVS: V1.1 Identity and Access Management
  • Trusted publishing
    OWASP SPVS: V3.2 Credential Hygiene

Detective controls

None mapped yet.

Observed in

  • Aqua Trivy VS Code Extension (incident)
  • Clinejection (incident)
