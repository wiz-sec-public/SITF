SITF technique T-R007: Harvest Data from Private Artifacts

Component: RegistryStage: Post-CompromiseID: T-R007

Attacker extracts sensitive data from private artifacts.

SITF technique T-R007 (Harvest Data from Private Artifacts) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Registry component (Container and artifact registries (NPM, Docker, PyPI)).

Risks that enable this technique

  • Overprivileged registry access
  • Secrets in artifacts
  • No audit log monitoring

Protective controls

  • Minimal registry permissions
    OWASP SPVS: V5.1 Access Audit
  • Artifact encryption
    OWASP SPVS: V3.4 Integrity of Artifacts

Detective controls

  • Secret scanning
    OWASP SPVS: V5.4 Detection & Monitoring
  • Detection infra on audit logs
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • GitLab Pipeline Hijack (red team engagement)
