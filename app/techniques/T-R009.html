SITF technique T-R009: Registry Infrastructure Destruction

Component: RegistryStage: Post-CompromiseID: T-R009

Attacker deletes packages, images, or corrupts registry infrastructure to disrupt software distribution and deployment.

SITF technique T-R009 (Registry Infrastructure Destruction) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Registry component (Container and artifact registries (NPM, Docker, PyPI)).

Risks that enable this technique

  • Overprivileged registry access
  • No backup and recovery
  • Lack of deletion protection
  • No audit log monitoring
  • Insufficient access controls on critical artifacts
  • No artifact deletion approval process

Protective controls

  • Minimal user permissions (registry)
    OWASP SPVS: V5.1 Access Audit
  • Regular artifact backups
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • Artifact deletion protection
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Artifact deletion approval workflow
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Immutable artifact storage
    OWASP SPVS: V3.4 Integrity of Artifacts
  • Registry recovery procedures
    OWASP SPVS: V5.3 Secure Maintenance Practices; V5.5 Incident Response & Recovery
  • Artifact retention policies
    OWASP SPVS: V3.4 Integrity of Artifacts

Detective controls

  • Detection infra on audit logs (registry)
    OWASP SPVS: V5.4 Detection & Monitoring
