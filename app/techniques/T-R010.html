SITF technique T-R010: Typosquatting

Component: RegistryStage: Initial AccessID: T-R010

Attacker publishes malicious packages with names similar to legitimate ones to trick developers into installing them by mistake.

SITF technique T-R010 (Typosquatting) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the Registry component (Container and artifact registries (NPM, Docker, PyPI)).

Risks that enable this technique

  • No package name verification
  • Lack of typosquatting detection
  • Developer mistakes during package installation
  • No package naming policies
  • Lack of security awareness training
  • Direct downloads from public registries

Protective controls

  • Local registry proxy with filtering
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Package name similarity checks
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Automated maintainer reputation and hygiene checks
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Security awareness training on package verification
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment
  • Package installation verification workflows
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Dependency review and approval process
    OWASP SPVS: V2.6 3rd Party Library Audit
  • Package popularity and reputation scoring
    OWASP SPVS: V2.6 3rd Party Library Audit

Detective controls

  • Typosquatting detection and prevention
