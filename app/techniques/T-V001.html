SITF technique T-V001: Abuse Credentials for VCS Access

Component: VCSStage: Initial AccessID: T-V001

Attacker uses stolen credentials to access VCS.

SITF technique T-V001 (Abuse Credentials for VCS Access) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Lack of 2FA / phishing protection
  • Credentials in org public repos
  • Credentials in public repos of org members
  • Credentials in workflow logs
  • Previous breaches
  • Fine-grained PATs not enforced
  • PATs without expiration
  • Broad-scope CLI OAuth tokens without expiry
  • Privileged accounts used for daily work

Protective controls

  • Mandatory MFA
    OWASP SPVS: V1.1 Identity and Access Management
  • IDP / SSO setup
    OWASP SPVS: V1.1 Identity and Access Management
  • Enforcing fine-grained PATs
    OWASP SPVS: V1.1 Identity and Access Management
  • Enforcing PAT expiration
    OWASP SPVS: V1.1 Identity and Access Management
  • Dedicated admin accounts for org owners
    OWASP SPVS: V1.1 Identity and Access Management; V5.1 Access Audit
  • IP allow list for token access
    OWASP SPVS: V1.1 Identity and Access Management

Detective controls

  • Secret scanning on all orgs
    OWASP SPVS: V5.4 Detection & Monitoring
  • Secret scanning on personal repos
    OWASP SPVS: V5.4 Detection & Monitoring
  • Token usage anomaly detection
    OWASP SPVS: V5.4 Detection & Monitoring
