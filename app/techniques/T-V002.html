SITF technique T-V002: Imposter Commits

Component: VCSStage: Post-CompromiseID: T-V002

Attacker commits code impersonating another developer.

SITF technique T-V002 (Imposter Commits) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • No commit signing required
  • Email verification not enforced
  • No code review process

Protective controls

  • Commit signing
    OWASP SPVS: V1.5 Source Code Management Hardening; V3.4 Integrity of Artifacts
  • Requiring code owner approval
    OWASP SPVS: V1.5 Source Code Management Hardening; V2.3 Code Review and Analysis
  • Branch protection rules
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Email verification enforcement
    OWASP SPVS: V1.5 Source Code Management Hardening

Detective controls

None mapped yet.
