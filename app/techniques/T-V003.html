SITF technique T-V003: Secret Exfiltration from Repo

Component: VCSStage: Discovery and Lateral MovementID: T-V003

Attacker extracts secrets from repository content or history.

SITF technique T-V003 (Secret Exfiltration from Repo) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Misconfigured repo - visibility (public when should be private)
  • Misconfigured VCS access - external contributors
  • Using untrusted webhooks
  • Dangling webhooks
  • Secrets committed to repo
  • Leaked secrets deleted but not revoked
  • Secret scanning limited to the primary org

Protective controls

  • Private repo visibility
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Webhook security review
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Branch protection rules
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Revoke leaked secrets, not just delete them
    OWASP SPVS: V2.5 Credential Hygiene

Detective controls

  • Secret scanning on all orgs
    OWASP SPVS: V5.4 Detection & Monitoring
  • Secret scanning on personal repos
    OWASP SPVS: V5.4 Detection & Monitoring
  • Detection infra on audit logs
    OWASP SPVS: V5.4 Detection & Monitoring
