SITF technique T-V004: Secret Exfiltration from Personal Repo

Component: VCSStage: Discovery and Lateral MovementID: T-V004

Attacker finds secrets in personal repos of org members.

SITF technique T-V004 (Secret Exfiltration from Personal Repo) is a Discovery and Lateral Movement technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Misconfigured repo - visibility
  • Using personal repos for work
  • Org members with public repos containing work content

Protective controls

  • Policy against using personal repos for work
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment
  • Security awareness training
    OWASP SPVS: V1.3 Security Requirements and Risk Assessment

Detective controls

  • Secret scanning on personal repos
    OWASP SPVS: V5.4 Detection & Monitoring
  • Detection infra on audit logs
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • Shai-Hulud 2.0 (incident)
