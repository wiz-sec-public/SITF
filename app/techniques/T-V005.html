SITF technique T-V005: VCS Vulnerability Exploitation

Component: VCSStage: Initial AccessID: T-V005

Attacker exploits vulnerability in VCS platform.

SITF technique T-V005 (VCS Vulnerability Exploitation) is a Initial Access technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Non-patched VCS instance
  • Known CVEs not addressed
  • Self-hosted VCS without security updates

Protective controls

  • Using managed VCS instances
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • Patching schedule
    OWASP SPVS: V5.3 Secure Maintenance Practices

Detective controls

  • Vulnerability scanning
    OWASP SPVS: V5.4 Detection & Monitoring
  • Security update monitoring
    OWASP SPVS: V5.4 Detection & Monitoring
