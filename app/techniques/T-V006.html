SITF technique T-V006: Turn Private Repos Public

Component: VCSStage: Post-CompromiseID: T-V006

Attacker changes repository visibility to public.

SITF technique T-V006 (Turn Private Repos Public) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Overprivileged VCS access
  • No approval for visibility changes
  • No audit log monitoring

Protective controls

  • Minimal VCS permissions
    OWASP SPVS: V1.5 Source Code Management Hardening; V5.1 Access Audit
  • Approval workflow for visibility changes
    OWASP SPVS: V1.5 Source Code Management Hardening
  • CSPM/CNAPP
    OWASP SPVS: V4.2 Compliance Checks; V5.4 Detection & Monitoring

Detective controls

  • Detection infra on audit logs
    OWASP SPVS: V5.4 Detection & Monitoring
