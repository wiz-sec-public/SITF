SITF technique T-V007: Clone Sensitive Repositories

Component: VCSStage: Post-CompromiseID: T-V007

Attacker clones private repositories to steal IP and source code.

SITF technique T-V007 (Clone Sensitive Repositories) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Overprivileged VCS access
  • No audit log monitoring
  • No DLP on network

Protective controls

  • Minimal VCS permissions
    OWASP SPVS: V1.5 Source Code Management Hardening; V5.1 Access Audit
  • Repository access reviews
    OWASP SPVS: V1.5 Source Code Management Hardening; V5.1 Access Audit

Detective controls

  • Detection infra on audit logs
    OWASP SPVS: V5.4 Detection & Monitoring
  • Network DLP
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • GitLab Pipeline Hijack (red team engagement)
