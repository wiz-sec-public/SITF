SITF technique T-V008: Malicious Repo Hosting

Component: VCSStage: Post-CompromiseID: T-V008

Attacker uses compromised VCS to host malicious repositories.

SITF technique T-V008 (Malicious Repo Hosting) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Overprivileged VCS access
  • No repository review process
  • Unlimited repository creation

Protective controls

  • Repository creation approval
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Resource quotas
    OWASP SPVS: V3.1 Security of Pipeline Environment; V5.2 Security Standard Enforcement

Detective controls

  • Repository security scanning
    OWASP SPVS: V5.4 Detection & Monitoring
  • Detection infra on audit logs
    OWASP SPVS: V5.4 Detection & Monitoring

Observed in

  • LiteLLM (October 2026) (incident)
  • Trivy Act II (incident)
