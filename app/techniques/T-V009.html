SITF technique T-V009: Mass Deletion of Repositories

Component: VCSStage: Post-CompromiseID: T-V009

Attacker deletes multiple repositories to cause data loss and operational disruption.

SITF technique T-V009 (Mass Deletion of Repositories) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Overprivileged VCS access
  • No backup and recovery
  • No audit log monitoring
  • Insufficient access controls on critical repositories
  • No repository deletion approval process
  • Lack of deletion protection

Protective controls

  • Minimal VCS user permissions
    OWASP SPVS: V1.5 Source Code Management Hardening; V5.1 Access Audit
  • Regular repository backups
    OWASP SPVS: V5.3 Secure Maintenance Practices
  • Repository deletion approval workflow
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Repository recovery procedures
    OWASP SPVS: V5.3 Secure Maintenance Practices; V5.5 Incident Response & Recovery
  • Deletion protection on critical repositories
    OWASP SPVS: V1.5 Source Code Management Hardening; V5.3 Secure Maintenance Practices

Detective controls

  • Detection infra on audit logs (VCS)
    OWASP SPVS: V5.4 Detection & Monitoring
  • Immutable audit logs
    OWASP SPVS: V5.4 Detection & Monitoring
