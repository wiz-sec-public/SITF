SITF technique T-V011: Git Tag/Reference Manipulation

Component: VCSStage: Post-CompromiseID: T-V011

Attacker force-pushes git tags or manipulates branch references to point to malicious commits, causing consumers to pull backdoored code.

SITF technique T-V011 (Git Tag/Reference Manipulation) is a Post-Compromise technique in the SDLC Infrastructure Threat Framework (SITF). It targets the VCS component (Version Control Systems (GitHub, GitLab, Azure DevOps)).

Risks that enable this technique

  • Tags not protected from force-push
  • No tag signing enforcement
  • Consumers reference actions/packages by mutable tags
  • No alerting on tag reference changes
  • Service accounts with tag push permissions
  • No approval workflow for tag operations

Protective controls

  • Tag protection rules — Prevent force-push and deletion of release tags
    OWASP SPVS: V1.5 Source Code Management Hardening
  • Tag signing enforcement — Require GPG/SSH signing for tag creation
    OWASP SPVS: V1.5 Source Code Management Hardening; V3.4 Integrity of Artifacts
  • Restrict tag push permissions — Limit tag creation/modification to specific roles or service accounts with MFA
    OWASP SPVS: V1.1 Identity and Access Management; V5.1 Access Audit
  • Pin actions/dependencies by SHA — Reference GitHub Actions and dependencies by immutable commit SHA instead of tags
    OWASP SPVS: V2.6 3rd Party Library Audit; V3.1 Security of Pipeline Environment
  • Tag operation approval workflow — Require approval for tag creation or modification on release branches
    OWASP SPVS: V1.5 Source Code Management Hardening; V4.3 Secure Deployment Practices

Detective controls

  • Tag mutation monitoring — Alert on tag force-push, deletion, or reference changes
    OWASP SPVS: V5.4 Detection & Monitoring
  • Audit log monitoring for tag operations — Monitor VCS audit logs for bulk tag modifications
    OWASP SPVS: V5.4 Detection & Monitoring
  • Tag-to-commit drift detection — Detect when tag references change to point to different commits
    OWASP SPVS: V5.4 Detection & Monitoring
