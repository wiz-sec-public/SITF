SITF technique library

SITF is an open threat framework for attacks on software development lifecycle (SDLC) infrastructure: developer endpoints and IDEs, version control (VCS), CI/CD pipelines, artifact and container registries, and production cloud. Each SITF technique is mapped to the risks that enable it and to protective and detective controls.

The library contains 82 techniques across 5 SDLC components and 3 attack stages (Initial Access, Discovery and Lateral Movement, Post-Compromise). Technique IDs use the prefix of their component: T-E (Endpoint/IDE), T-V (VCS), T-C (CI/CD), T-R (Registry), T-P (Production/Cloud).

Also available as techniques.json, llms-full.txt, and an interactive explorer.
